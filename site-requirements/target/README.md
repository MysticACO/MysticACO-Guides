# Target

## **Requirements**

* Target Accounts are required **(Account Username + Account Password)**
* Each Target **Checkout Profile** email must have a matching **Account** within the **Accounts Tab**.&#x20;
* Accounts with order history are preferred. New accounts are accepted, but you risk more cancellations with fresh accounts.&#x20;
* Each submission must have unique addresses or Jigged variations [Click Here](../../how-to-jig.md)
* IMAP is **required** in order for us to login without needing you to send 2FA codes.
* Hard cards are king. Minimize the number of virtual cards you provide.&#x20;
